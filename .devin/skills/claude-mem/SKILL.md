# Claude-Mem — Persistent Memory

Сохранение контекста между сессиями: архитектурные решения, технические наблюдения, решённые проблемы.

## Что фиксировать

- **Архитектура** — почему выбран подход, отклонённые альтернативы, ключевые паттерны
- **Техника** — настройка окружения, зависимости, нетривиальные конфиги, обходные пути
- **Проект** — структура кодовой базы, паттерны стиля, workflow, тестовые окружения
- **Решённые проблемы** — сложные баги, корневые причины, подводные камни

## Формат

Кратко (1-3 предложения), конкретно (точные файлы, команды), полезно для будущих сессий.

```markdown
## БД: PostgreSQL 15, порт 5432, .env.local
Миграции: `npm run db:migrate` | Reset: `npm run db:reset`

## API: REST/Express, src/routes/, JWT auth (src/middleware/auth.ts)
```

## Практика

1. Начало сессии → прочитай контекст
2. Решил проблему → запиши причину и фикс
3. Нашёл паттерн → запиши
4. Конец сессии → сохрани наблюдения
