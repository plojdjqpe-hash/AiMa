Источник: [ruvnet/ruflo](https://github.com/ruvnet/ruflo) (MIT)

## SPARC Methodology

5-фазный подход к разработке с quality gates:

1. **Specification** — Чёткие требования и критерии приёмки
2. **Pseudocode** — Высокоуровневый алгоритм перед кодом
3. **Architecture** — Дизайн компонентов и их взаимодействий
4. **Refinement** — Итеративное улучшение с тестированием
5. **Completion** — Финальная верификация и документация

Каждая фаза имеет quality gate — переход к следующей только при выполнении критериев.

## Swarm Patterns

### Координация агентов
- **Divide & Conquer** — разбей задачу на подзадачи, назначь агентам
- **Pipeline** — агенты работают последовательно, каждый обрабатывает результат предыдущего
- **Consensus** — несколько агентов решают одну задачу, результаты сравниваются
- **Specialist Routing** — задача направляется к агенту с нужной специализацией

### Self-Learning
- Агенты запоминают успешные стратегии
- Неуспешные подходы помечаются для избежания
- Knowledge graph обновляется после каждой задачи

## Применение в разработке

1. **Планирование** — декомпозиция цели через Goals → план задач
2. **Архитектура** — ADR для фиксации решений, DDD для моделирования
3. **Реализация** — SPARC methodology с quality gates
4. **Тестирование** — TestGen для генерации тестов, Browser для E2E
5. **Security** — Security Audit + AI Defence на каждом PR
6. **Документация** — автоматическая генерация через Docs
7. **Деплой** — Workflows для автоматизации релиза
