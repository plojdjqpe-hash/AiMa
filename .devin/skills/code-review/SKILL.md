# Code Review

## Направления ревью (параллельно)

1. **Стандарты проекта** — аудит на соответствие CLAUDE.md/AGENTS.md/lint config
2. **Баги в diff** — только значимые, без nitpicks
3. **Проблемы нового кода** — security, некорректная логика
4. **Контекст истории** — git blame, влияние на существующий код

## Отмечай только HIGH SIGNAL

**ДА:** синтаксические ошибки, ошибки типов, отсутствующие импорты, явные логические ошибки, однозначные нарушения стандартов (цитируй правило)

**НЕТ:** стиль, потенциальные issues зависящие от state, субъективные улучшения

**Не уверен → не отмечай.** False positives разрушают доверие.

## Процесс

1. Предпроверка (PR закрыт/драфт/тривиальный? → пропусти)
2. Собери стандарты проекта
3. Суммируй изменения
4. 4 параллельных ревью
5. Валидация каждого issue
6. Фильтрация (только 80%+ confidence)
7. Отчёт: файл:строка + описание + причина
