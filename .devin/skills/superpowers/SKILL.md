# Superpowers

## 1. Brainstorming

**Перед любой творческой работой. НЕ пиши код без утверждённого дизайна.**

1. Изучи контекст (файлы, docs, коммиты)
2. Уточняющие вопросы — по одному
3. Предложи 2-3 подхода с компромиссами
4. Представь дизайн, сохрани в `docs/specs/`
5. Самопроверка → переход к планированию

## 2. Планирование

**Пиши план для инженера с нулевым контекстом. Каждый шаг — одно действие (2-5 мин).**

- Точные пути файлов, полный код, DRY/YAGNI/TDD
- Никаких "TBD"/"TODO"/"implement later"
- Структура: Файлы → Тест(RED) → Запуск → Реализация(GREEN) → Запуск → Коммит

## 3. TDD

```
НЕТ ПРОДАКШН-КОДА БЕЗ ПАДАЮЩЕГО ТЕСТА
```

**RED** → напиши тест, он ДОЛЖЕН упасть | **GREEN** → минимальный код для прохождения | **REFACTOR** → улучши, тесты зелёные

## 4. Отладка

**Не чини без корневой причины.** 4 фазы:

1. **Расследование** — воспроизведи, собери данные
2. **Анализ** — что изменилось, какие компоненты, паттерн?
3. **Гипотеза** — проверь без изменения prod-кода
4. **Реализация** — тест(RED) → фикс(GREEN) → рефакторинг

3 неудачных попытки → архитектурный ревью.

## 5. Верификация

Перед "готово": тесты ✓ линтер ✓ сборка ✓ спека покрыта ✓ нет TODO ✓ атомарные коммиты ✓
